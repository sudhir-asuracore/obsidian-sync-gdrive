2. Description of the Service

Sync Drive is an open-source client-side plugin that enables users of the Obsidian desktop and mobile application to synchronize their local notes, vaults, and settings with their own Google Drive storage accounts using official Google Drive APIs.

4. Encryption Key and Data Responsibility

If you choose to use the optional client-side AES-256-GCM encryption feature:
